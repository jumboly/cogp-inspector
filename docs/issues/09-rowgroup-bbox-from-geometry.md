# 統計値が無い Row Group の bbox をジオメトリから計算する

## なぜ検討が必要か
MVP では統計値だけで Row Group bbox を求め、無ければ「bbox 不明」と表示する（design.md D4）。covering 列も geospatial_statistics も無いファイルでは地図に何も描けない。

## 現在わかっていること
- 計算にはジオメトリ列（WKB）を読んでデコードする必要があり、読むバイト数が大きい
- 「最初は Footer だけを読む」方針と衝突するため、ボタン操作で明示的に実行する形にしたい
- 読んだ量は Range 記録に残し、「統計が無いとこれだけ読む必要がある」ことも見せられる
